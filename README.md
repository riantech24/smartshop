# 🛍️ SmartShop v2.0 — Asisten Belanja Cerdas

PWA + Backend API untuk lacak harga, bandingkan, dan hemat saat belanja.

## 📦 Struktur
- `frontend/` — PWA (HTML/CSS/JS)
- `backend/` — Node.js API + Scraper + Afiliasi

## 🚀 Quick Start

### Backend
```bash
cd backend
npm install
cp .env.example .env   # isi API key
npm start
# → http://localhost:3000

### Frontend
cd frontend
npx serve -s . -p 5000
# → http://localhost:5000
